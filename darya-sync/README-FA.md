# داریا-سینک (DaryaSync) 🔄

برنامهٔ ویندوزی همگام‌سازی خودکار بین **ووکامرس** (از طریق افزونهٔ *Darya Bridge*) و **نرم‌افزار حسابداری داریا**.

این برنامه یک فایل اجرایی تکی (`DaryaSync.exe`) است؛ نیازی به نصب ندارد و همه‌چیز (پنل مدیریت، تنظیمات، لاگ) داخل همان یک فایل است. کنار فایل اجرایی فقط دو فایل `config.json` (تنظیمات) و `state.json` (وضعیت/نشانگرها) نگه‌داری می‌شود.

> ## ✨ تغییرات نسخه ۱.۰.۱ — رفع کامل مشکل فونت فارسی
> - **دیگر هیچ پنجرهٔ سیاه کنسولی باز نمی‌شود.** کنسول ویندوز فونت فارسی ندارد و حروف را مربع نشان می‌داد؛ حالا برنامه به‌صورت GUI اجرا می‌شود و **پنل فارسی به‌طور خودکار در مرورگر باز می‌شود** — همان‌جا همه‌چیز (لاگ، وضعیت، تنظیمات) با فونت فارسیِ درست و راست‌چین دیده می‌شود.
> - دکمهٔ **⏻ خروج** به پنل اضافه شد: با یک کلیک برنامه به‌شکل تمیز متوقف می‌شود (یا در CMD: `DaryaSync.exe exit`).
> - **تک‌نمونه‌ای:** اگر برنامه قبلاً اجرا شده باشد، اجرای دوباره فقط همان پنل را در مرورگر باز می‌کند و خطای پورت نمی‌دهد.
> - اگر برنامه را مستقیم از داخل WinRAR/7-Zip اجرا کنید، در پنل هشدار می‌دهد که «اول Extract کنید» تا تنظیمات موقت نشود.

## چه کاری انجام می‌دهد؟

هر ۱۵ ثانیه وظایف فعال را بررسی می‌کند و در زمان مقرر اجرایشان می‌کند:

| وظیفه | کار پیش‌فرض | توضیح |
|---|---|---|
| **همگام‌سازی رویدادها (trigger)** | هر ۵ دقیقه | فرمان اجرای صف افزونه در وردپرس و اجرای صف همگام‌سازی در داریا |
| **کاربران و نقش‌ها (roles)** | هر ۶۰ دقیقه | کاربران ووکامرس → `v1/users/sync` داریا (ساخت/بروزرسانی مشتری و نقش‌ها بر اساس نقشهٔ نقش) |
| **محصولات (products)** | هر ۱۲۰ دقیقه | محصولات ووکامرس → `v1/products/upsert` داریا (دسته‌های ۵۰تایی) |
| **سفارش‌ها (orders)** | هر ۱۰ دقیقه | سفارش‌های جدید (بر اساس نشانگر زمانی) → ساخت فاکتور فروش در داریا (یکی‌یکی) |
| **سبدهای رهاشده (carts)** | هر ۱۵ دقیقه | سبدهای رهاشدهٔ جدید → `v1/abandoned-carts` داریا (دسته‌های ۲۵تایی) |

برای سفارش‌ها و سبدها «نشانگر زمانی» (since) در `state.json` ذخیره می‌شود تا فقط موارد جدید ارسال شوند و بعد از قطعی اینترنت، ادامه از همان‌جا بگیرد.

## نصب روی ویندوز

1. **اول فایل زیپ را Extract کنید** (روی آن راست‌کلیک ← Extract All) و `DaryaSync.exe` را از پوشهٔ واقعی اجرا کنید — نه از داخل WinRAR. مثلاً:
   ```
   C:\DaryaSync\
   ```
2. نیازی به ساختن دستی `config.json` نیست؛ برنامه در اولین اجرا خودش می‌سازد و بعد از داخل پنل تنظیم می‌کنید.
3. روی `DaryaSync.exe` دوبار کلیک کنید. **پنجرهٔ سیاهی باز نمی‌شود** — به‌جای آن، پنل مدیریت فارسی خودکار در مرورگر پیش‌فرض باز می‌شود:
   ```
   http://127.0.0.1:8585
   ```
   اگر باز نشد، خودتان در مرورگر همین آدرس را باز کنید. برنامه در پس‌زمینه در حال اجراست.
4. برای **خروج از برنامه**: در پنل روی دکمهٔ قرمز **⏻ خروج** کلیک کنید؛ یا در CMD:
   ```bat
   DaryaSync.exe exit
   ```

> 💡 اگر ویندوز هنگام اجرا پیام SmartScreen (Windows protected your PC) داد: **More info ← Run anyway** — این پیام فقط به‌دلیل امضای دیجیتال نداشتن فایل است.
>
> 💡 فلگ‌ها: `-no-open` (باز نکردن خودکار مرورگر)، `-config "C:\مسیر پوشه"` (تعیین دستی پوشهٔ config/state/log). لاگ فایل هم در پوشهٔ برنامه ذخیره می‌شود.

## تنظیمات

در پنل، بخش **⚙️ تنظیمات** را پر کنید و «ذخیره تنظیمات» را بزنید:

| فیلد | توضیح |
|---|---|
| **آدرس نرم‌افزار داریا** | مثل `https://darya.yourcompany.com` (اگر http/https ننویسید، خودکار `https://` می‌شود؛ برای localhost خودکار `http://`) |
| **کلید API داریا** | کلید با پیشوند `dk_` که از بخش تنظیمات API در خود داریا می‌گیرید |
| **آدرس سایت وردپرس** | مثل `https://shop.yourcompany.com` |
| **Secret افزونه** | همان Secretی که در تنظیمات افزونهٔ *Darya Bridge* در وردپرس تعیین کرده‌اید |
| **آدرس وب پنل (listen)** | پیش‌فرض `127.0.0.1:8585` — پنل فقط روی همین سیستم قابل دسترسی است |
| **وظایف** | برای هر وظیفه می‌توانید فعال/غیرفعال و بازهٔ اجرا (دقیقه) را تغییر دهید |

بعد از ذخیره، دکمهٔ **🔌 تست اتصال‌ها** را بزنید؛ اگر هر دو کارت (داریا و وردپرس) «متصل ✔» شدند، همه‌چیز آماده است. برای اجرای بی‌درنگ، **⚡ همگام‌سازی فوری** یا دکمهٔ «اجرای فوری» هر کارت وظیفه را بزنید.

### تنظیم سمت وردپرس
افزونهٔ **Darya Bridge** باید نصب و فعال باشد و Secret آن با همین Secretی که اینجا وارد می‌کنید یکی باشد. مسیر REST افزونه:
```
{آدرس سایت}/wp-json/darya-bridge/v1/status?secret=...
```

### تنظیم سمت داریا
در داریا یک کلید API بسازید (پیشوند `dk_`) و در این برنامه وارد کنید. مسیر پایهٔ API:
```
{آدرس داریا}/api/index.php?path=v1/ping
```

## اجرای خودکار هنگام روشن شدن ویندوز (Startup)

1. در منوی استارت عبارت `shell:startup` را تایپ و Enter بزنید (پوشهٔ Startup باز می‌شود).
2. روی `DaryaSync.exe` راست‌کلیک → **Send to → Desktop (create shortcut)**، سپس میان‌بر دسکتاپ را با **کات (Ctrl+X)** بردارید و در پوشهٔ Startup **پیست (Ctrl+V)** کنید.
   - یا: راست‌کلیک در پوشهٔ Startup → **New → Shortcut** → مسیر فایل exe را بدهید (پیشنهاد: با فلگ `-open` تا پنل هم باز شود):
     ```
     C:\DaryaSync\DaryaSync.exe -open
     ```
3. تمام؛ از دفعهٔ بعد با روشن شدن ویندوز، برنامه خودکار اجرا می‌شود.

> نکته: اگر می‌خواهید پنجرهٔ کنسول دیده نشود، می‌توانید میان‌بر را در Properties روی Minimized بگذارید.

## فایل‌های کنار برنامه

| فایل | توضیح |
|---|---|
| `config.json` | تنظیمات (آدرس‌ها، کلیدها، وظایف) |
| `state.json` | نشانگرهای همگام‌سازی و نتیجهٔ آخرین اجرای هر وظیفه |
| `darya-sync.log` | لاگ کامل با تاریخ و ساعت |

پشتیبان‌گیری = کپی همین سه فایل + خود exe.

## سوالات متداول

**پنل باز نمی‌شود؟**
- مطمئن شوید کنسول برنامه باز است و خطای وب‌سرور ندارد.
- اگر فیلد listen را عوض کرده‌اید، آدرس جدید را باز کنید (مثلاً `127.0.0.1:9000`).
- فایروال/آنتی‌ویروس را بررسی کنید (پورت 8585 روی 127.0.0.1).

**کارت اتصال‌ها «قطع ✖» است؟**
- داریا: آدرس و کلید `dk_` را چک کنید؛ داریا در دسترس است؟ (`path=v1/ping` را در مرورگر امتحان کنید)
- وردپرس: افزونهٔ Darya Bridge فعال است؟ Secret درست است؟ آدرس سایت با `https://` صحیح است؟

**سفارشی منتقل نشد؟**
- کارت «سفارش‌ها» خطا دارد؟ متن خطا را ببینید (مثلاً محصول با SKU ناموجود یا دادهٔ ناقص).
- بعد از اصلاح، دکمهٔ «اجرای فوری» سفارش‌ها را بزنید؛ نشانگر since تا آخرین سفارشِ *موفق* جلو می‌رود، پس موارد ناموفق دوباره تلاش می‌شوند.

**مصرف رم/شبکه؟**
- برنامه سبک است و فقط در بازه‌های تعیین‌شده درخواست می‌زند. بازه‌ها را از تنظیمات می‌توانید کم/زیاد کنید (حداقل ۱ دقیقه).

**تغییر پورت پنل؟**
- در تنظیمات فیلد listen را عوض کنید و ذخیره کنید؛ وب‌سرور بلافاصله روی پورت جدید می‌آید.

**آیا داده‌ها امن هستند؟**
- پنل فقط از همان کامپیوتر (`127.0.0.1`) قابل دسترسی است و در لاگ، کلیدها به‌صورت ماسک‌شده نمایش داده می‌شوند. ترافیک فقط بین سایت شما و سرور داریاست.
