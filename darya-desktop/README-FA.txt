  داریا دسکتاپ — نرم‌افزار حسابداری و مدیریت کسب‌وکار (نسخه ویندوزی)
  Darya Desktop v1.1.1
═══════════════════════════════════════════════════════════════

نرم‌افزار حسابداری فارسی روی سیستم خودتان — بدون نیاز به هاست و اینترنت
(مشابه نرم‌افزارهای دسکتاپ حسابداری): فاکتور فروش/خرید/برگشتی، انبار و
کاردکس، اسناد حسابداری و دفتر کل، صندوق و بانک و چک، مشتریان، کارمندان
و مبلغان، حقوق و دستمزد، گزارش‌ها، اکسل، نقش‌ها و دسترسی، موبوآردر.

─────────────────────────────
■ اجرا (فقط ۳ قدم)
─────────────────────────────
۱) کل پوشه DaryaDesktop را Extract کنید (اجرا از داخل WinRAR ممنوع!)
   مثلاً:  C:\DaryaDesktop\
۲) روی  Darya.exe  دوبار کلیک کنید.
۳) برنامه خودش پایگاه داده را می‌سازد و پنجره نرم‌افزار باز می‌شود.

■ ورود اولیه:
   نام کاربری:  admin
   رمز عبور:    admin123
   ⚠ بعد از اولین ورود، از منوی «کاربران» رمز را عوض کنید!

■ خروج از برنامه:
   در CMD داخل پوشه برنامه:   Darya.exe stop
   (بستن پنجره برنامه، سرویس را نمی‌بندد؛ با stop ببندید)

■ پشتیبان‌گیری:
   کافی است هر چند روز یک‌بار از فایل  app\data\darya.sqlite  کپی بگیرید.

─────────────────────────────
■ اتصال سایت ووکامرس (سینک)
─────────────────────────────
۱) افزونه Darya Bridge را در وردپرس نصب و فعال کنید و Secret بسازید.
۲) کلید API داریا در فایل  data\api-key.txt  است (پیشوند dk_).
۳) برنامه DaryaSync.exe (بسته جدا) را اجرا کنید و در تنظیماتش:
      آدرس داریا:        http://127.0.0.1:8765
      کلید API داریا:    (محتوای api-key.txt)
      آدرس سایت:         https://your-shop.com
      Secret افزونه:     (همان Secret وردپرس)
   از این پس سفارش‌ها، محصولات، مشتریان و نقش کاربران خودکار
   بین سایت و نرم‌افزار داریا روی سیستم شما همگام می‌شوند.

─────────────────────────────
■ رفع اشکال نسخه ۱.۱.۱
─────────────────────────────
• خطای «Call to undefined function mb_internal_encoding» هنگام اولین
  اجرا در نسخه ۱.۱.۰ برطرف شد — حالا مرحله راه‌اندازی اولیه نیز با
  افزونه‌های کامل PHP (mbstring و pdo_sqlite و ...) اجرا می‌شود.
• لاگ وب‌سرور برای عیب‌یابی در  data\php-server.log  ذخیره می‌شود.

■ اگر باز هم خطا دیدید:
• متن کامل خطا در پیام راه‌اندازی نمایش داده می‌شود؛ از آن عکس بگیرید.
• مطمئن شوید پکیج را «کامل» Extract کرده‌اید (پوشه php و ext موجود باشد).
• پورت 8765 باید آزاد باشد.
• اگر ویندوز پیام SmartScreen داد: More info ← Run anyway
  (فقط به‌خاطر نداشتن امضای دیجیتال است)

─────────────────────────────
■ نکته‌ها
─────────────────────────────
• همه داده‌ها فقط روی سیستم خودتان است و هیچ‌جا ارسال نمی‌شود.
• سرویس داخلی روی 127.0.0.1:8765 اجرا می‌شود؛ این پورت باید آزاد باشد.
• اگر پنجره برنامه بسته شد و خواستید دوباره وارد شوید، فقط Darya.exe را
  دوباره اجرا کنید (همان جلسه قبلی باز می‌شود).
